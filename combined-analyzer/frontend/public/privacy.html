Privacy Policy

Combined Analyzer is a classroom application for analyzing software repositories and managing analysis reports. This policy describes its use of personal information.

Effective November 12, 2026. Contact: gastonhschw@gmail.com.

Information the application processes

  • Google sign-in: Google account identity, email address, and basic profile information made available during sign-in, such as name and profile picture. Google authenticates you through Supabase; the application does not receive your Google password.
  • Classroom activity: user profiles, roles, class memberships, and administrator assignments.
  • Submitted material: uploaded or imported repository files, repository metadata, selected files, user stories, diagrams, analysis requests, reports, comparisons, and report-chat content.
  • Optional connections: GitHub authorization credentials when you connect GitHub, and API credentials you provide to use the analysis service. GitHub credentials stored by the backend are encrypted.
  • Technical information: authentication sessions and browser storage needed to operate the application, plus service logs used for operation and troubleshooting.

How information is used and shared

Google account information is used to sign you in, identify your application account, and enforce access to classes and repositories. It is not requested for advertising. The Google connection requests basic sign-in information, not access to Gmail or Google Drive.

Class administrators can inspect enrolled students’ repositories and analysis results as part of classroom use. Application operators can access information as needed to administer and troubleshoot the service.

Supabase provides authentication and database storage; Render hosts the application. GitHub processes repository access when you connect it. When you request AI analysis or report chat, relevant submitted files, diagrams, prompts, and report content are sent to the configured analysis provider through the TAMU API service. Do not submit passwords, confidential material, or personal information you are not authorized to share.

These providers process information under their own applicable terms and privacy policies. Combined Analyzer’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Storage, retention, and security

Account, classroom, and analysis records are stored in the application database. Imported source files are stored on the backend filesystem. Sessions and some connection settings are stored in your browser. Access is controlled through authentication and application permissions; no service can guarantee absolute security or uninterrupted storage.

There is no automatic fixed retention period. Records remain until removed through available application controls or by an administrator. Hosted-service logs and backups may follow separate provider retention schedules. The application is not a backup service; retain your own source files.

Your choices and requests

You can sign out, use available repository deletion controls, and revoke Google or GitHub access through those providers’ account settings. Revoking provider access does not itself delete previously stored application records.

For access, correction, or deletion requests, contact gastonhschw@gmail.com and identify the account concerned. Account deletion requires administrator action; related source files must also be removed from backend storage. We may need to verify your identity before acting on a request.
